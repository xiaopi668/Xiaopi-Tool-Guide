# 文件与目录的十个命令

> pwd 到 rm 走一遍，顺手记住哪一条会吃掉你的数据。

`终端与系统` · 建议 12 分钟 · 入门

## 学完这一节，你会

- 分清绝对路径与相对路径
- 用 pwd、ls、cd 安全地在目录间移动
- 知道 cp、mv、rm 各自的副作用
- 删除任何东西之前先确认路径

## 路径是一棵树

文件系统是一棵倒着的树，最上面是根目录 `/`。**绝对路径**从 `/` 写起，在任何目录敲都指向同一处；**相对路径**从你当前所在目录算起，换个位置含义就变了。

三个记号天天用：`~` 是家目录（`/Users/你的名字` 或 `/home/你的名字`），`.` 是当前目录，`..` 是上一级。写脚本用绝对路径，手敲用相对路径省事。

## 看清单前状态

```bash
$ pwd; ls -la ~/Projects
/Users/xiaopi/Projects
total 16
drwxr-xr-x   4 xiaopi  staff   128  3 14 09:30 .
drwxr-xr-x+ 38 xiaopi  staff  1216  3 14 09:30 ..
drwxr-xr-x   9 xiaopi  staff   288  3 14 09:18 prompt学校
-rw-r--r--   1 xiaopi  staff    42  3 14 09:29 notes.md
```

> 第一列首字母 d 是目录，横线是普通文件；后面九位是权限，第五课细讲。最后两列是修改时间和名字。

## 十个命令，够用一整年

| 命令 | 作用 | 例子 |
| --- | --- | --- |
| pwd | 打印当前目录的绝对路径 | pwd |
| ls | 列出目录内容 | ls -la ~/Projects |
| cd | 切换目录 | cd ../assets |
| mkdir | 新建目录，-p 可以一次建多层 | mkdir -p src/components |
| cp | 复制文件，目录要加 -r | cp -r src src.bak |
| mv | 移动，或者改名，同一个命令 | mv notes.md notes-2024.md |
| rm | 删除，-i 每删一次都问 | rm -i draft.md |
| touch | 建空文件，或更新修改时间 | touch .env |
| cat | 整份打印小文件 | cat .gitignore |
| open | 用默认程序打开（仅 macOS） | open . |

## cd 的四种走法

`cd /tmp` 走绝对路径；`cd assets/js` 走相对路径；`cd ..` 回上一级；`cd ~` 或光敲一个 `cd` 回家目录；`cd -` 回到上一个待过的目录，两个目录来回切时最省事。

目录名带空格必须处理：`cd "My Documents"` 或 `cd My\ Documents`。直接敲 `cd My Documents` 会被切成两个参数，报 `cd: too many arguments`。

## 建目录、复制、改名，一步不漏

```bash
$ mkdir -p ~/tmp-demo/src/utils && cd ~/tmp-demo && touch src/utils/log.js && cp -r src src.bak && mv src.bak src-old && ls
src
src-old
```

> && 表示前一条成功才执行后一条。mv 在这里只是改名，src.bak 这个目录名从此不存在。

## 在临时目录里做完这套动作

### 1. 一次建出三层目录

在 `~` 下执行 `mkdir -p ~/tmp-demo/a/b/c`，-p 会顺手把缺的父目录补上。

### 2. 复制整个目录

`cp -r ~/tmp-demo/a ~/tmp-demo/a-copy`，然后 `ls ~/tmp-demo` 确认两份都在。

### 3. 改名，明白 mv 不留原件

`mv ~/tmp-demo/a-copy ~/tmp-demo/a-renamed`，a-copy 这个名字随即消失。

### 4. 删整个实验目录前先看清楚

先 `ls -la ~/tmp-demo` 核对，再 `rm -rf ~/tmp-demo`，最后 `ls ~` 确认它没了。

> **注意：rm -rf 没有回收站**
>
> `rm` 删掉的文件不进废纸篓，终端也没有撤销键。一旦回车，只能靠备份或恢复工具去捞。
>
> `rm -rf ~/Projects` 会递归删掉整个目录，不确认、不提示、不报错。真正致命的是变量拼错：`rm -rf $DIR/` 在 DIR 为空时展开成 `rm -rf /`，系统当场报废。
>
> 两条硬规矩：删之前对同一个路径敲一次 `ls`；写脚本时在开头加 `set -u`，让未定义变量直接报错，而不是悄悄变成空字符串。

## 空格与特殊字符怎么处理

Shell 用空格切分参数，路径里带空格就会被当成两个参数。三种写法都行：`cp "my file.txt" /tmp`、`cp my\ file.txt /tmp`，以及用 Tab 让 Shell 自己帮你转义。

文件名里出现 `$`、`&amp;`、`(` 这类字符时，用单引号包住最稳，单引号里一个字符都不解释。养成习惯：路径一律先 Tab 补全，补不出来就是打错了。

## 引号保住了空格

```bash
$ cd "/Users/xiaopi/My Documents" && pwd
/Users/xiaopi/My Documents
```

> 引号保住空格。换成 cd /Users/xiaopi/My\ Documents 效果相同；不加引号会报 cd: too many arguments。

## 三个你一定会撞上的报错

`mkdir: a: File exists`：目录已存在，mkdir 不会覆盖，加 `-p` 就静默跳过。

`cp: src is a directory (not copied)`：复制目录忘了 `-r`。

`rm: draft.md: No such file or directory`：名字或路径不对，先用 `ls` 核对。还有一种情况是文件名里带了不可见字符，用 Tab 补全就能避开。

> **提示：把 rm -i 设成默认值**
>
> 在 `~/.zshrc` 里加一行 `alias rm="rm -i"`，再执行 `source ~/.zshrc`，以后每次删除都会先问你一句。
>
> 代价是批量删除会被问很多次；而带 `-f` 的 `rm -rf` 会把 `-i` 顶掉，照样一句不问就删，这也是它危险的原因之一。真正可靠的保护是把重要目录交给 Git。

## 动手练一练

在 ~/tmp-demo 里把建、复制、改名、删除各走一遍，最后亲手把这个目录删掉，再回 ~ 确认它真的没了。

1. 一次建出三层目录 —— `mkdir -p ~/tmp-demo/a/b/c`
2. 复制整个目录，再改名 —— `cp -r ~/tmp-demo/a ~/tmp-demo/a-copy && mv ~/tmp-demo/a-copy ~/tmp-demo/a-ok`
3. 用 ls 确认路径后整体删除 —— `ls -la ~/tmp-demo && rm -rf ~/tmp-demo`

**完成标准**：ls ~ 里已经看不到 tmp-demo 这个目录，而且你能说清 rm -rf 为什么不能随手敲。

## 小测验

<details>
<summary>展开题目与答案（3 题）</summary>

**1. 哪条命令会把 src 目录连同里面的文件一起复制成 src.bak？**

- A. cp src src.bak
- B. cp -r src src.bak
- C. mv src src.bak
- D. mkdir src.bak

<details><summary>答案</summary>

**B**。目录复制必须加 r 参数递归处理，否则系统会直接报错说 src 是个目录。mv 是移动或者改名，原目录不会留下副本，想留原件只能用 cp。

</details>

**2. 路径里有空格，哪条一定能正确执行？**

- A. cd My Documents
- B. cd "My Documents"
- C. cd My Documents/
- D. cd Documents

<details><summary>答案</summary>

**B**。引号把整串当成一个参数交给 cd。不加引号时，Shell 会先按空格把它切成两个参数，cd 收到两个路径就报参数太多，所以路径带空格一律加引号。

</details>

**3. 在空目录里执行 rm -rf $DIR/ 而 DIR 未定义，会发生什么？**

- A. 什么都不删
- B. 只删当前目录
- C. 展开成 rm -rf /，从根目录开始递归删除
- D. 会要求你确认

<details><summary>答案</summary>

**C**。未定义变量展开成空字符串，命令实际就是 rm -rf /，从根目录递归删除。脚本开头加 set -u，可以让这类未定义变量当场报错。

</details>

</details>

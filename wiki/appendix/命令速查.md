# 命令速查

> 按工具分组。复制到终端前先看清参数，尤其是标着「危险」的命令。
>
> Windows 一列默认使用 PowerShell；标着「—」的命令只有 macOS / Linux 提供。
> macOS 与 Linux 同为 POSIX 系统，但用户态工具不同（BSD 与 GNU），个别命令的选项并不通用，见每节末尾的差异说明。

> **macOS 与 Linux 的差异**
>
> - `ss` 只有 Linux 有；macOS 用 `lsof -iTCP -sTCP:LISTEN -P -n`
> - `ls --help` 是 GNU 选项；macOS 的 BSD `ls` 不认，改看 `man ls`
> - `sed -i`：macOS 必须写成 `sed -i ''`，Linux 可直接跟表达式
> - `date -d`、`grep -P`、`find -printf`、`stat -c`、`readlink -f`、`timeout` 都是 GNU 专有，macOS 默认没有
> - 需要 GNU 工具时：`brew install coreutils`，命令会带 `g` 前缀，如 `gsed`、`gdate`

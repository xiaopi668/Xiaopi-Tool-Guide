# 编辑快捷键：多光标、行操作、快速跳转

> 同一处改动要在四十行里重复，就别再复制粘贴了

`VS Code` · 建议 14 分钟 · 基础

## 学完这一节，你会

- 用 ⌘D 一次改掉同一个词的十几处
- 在任意位置点一下就能加光标
- 不碰鼠标完成整行的移动、复制、删除
- 用 F12 和返回键在代码里来回跳

## 浪费时间的不是打字，是重复

写代码时最常见的浪费不是打字慢，是**同一件小事重复几十遍**：给十行对象加同一个字段、把四处的颜色值从 #111 换成 #000、给三十行末尾补逗号。手改一遍两分钟，改漏一处要在浏览器里排查十分钟。

多光标（multi-cursor）解决的就是这件事：同时开出多个光标，一次输入，多处生效。

## ⌘D 和查找替换的区别

「全部替换」按文本动手，改的是整个文件，包括注释、字符串和你根本没看过的角落；**多光标是可见的**，每个光标停在哪你都看得见，改完扫一眼就知道对不对。

但两者都有边界：改**变量名**时正确工具是重命名符号（Rename Symbol，F2），它会理解作用域，不会动到同名的字符串。⌘D 只适合改颜色值、字段名、成段重复的文本这类「本来就是一回事」的内容。

## 跳转：别再用眼睛找

光标停在函数名上按 F12，跳到它的定义；按 ⌃ 减号（Windows 是 Ctrl+Alt+减号）回到刚才的位置，可以连着按，一路往回退。⌥F12（Alt+F12）是预览定义（Peek Definition），不跳走，就在当前文件上方弹一个小窗，看两眼按 Esc 关掉。

函数名是灰色、F12 按下去没反应，通常是这个符号没被导进当前文件，或者语言服务没启动：右下角语言模式不对、项目没装依赖、tsconfig 的路径写错，都会这样。

> **注意：三个真会咬人的坑**
>
> **忘了按 Esc。**多光标状态下继续往下写，之后每次输入都会同时作用在每一个光标上，一次删除能删掉一大片。发现不对立刻按 Esc 回到单光标，再连按几次 ⌘Z（Ctrl+Z）撤回。
>
> **⌘⇧L 选太宽。**在整个文件里选中所有同名文字再改名，字符串和注释里的会一起变。改名用 F2。
>
> **⌥ 点错位置。**多点出来的光标会让你下一次输入出现在不相干的行上；⌘U（Ctrl+U）可以只撤掉最后加的那一个。

## 一段可以拿来练手的代码

```text
.card { color: #111; padding: 24px; }
.note { color: #111; padding: 12px; }
.tag  { color: #111; padding: 4px; }
.btn  { color: #111; padding: 8px; }
```

> 把光标放进第一个 #111，连按四次 ⌘D（Ctrl+D），输入 #000，四处颜色一次改完。然后按 Esc，连按几次 ⌘Z 撤回，再用 ⌥ 点击逐行加光标改 padding，练一遍。

## 同一件小事，两种做法

| 手改 | 多光标 |
| --- | --- |
| 用鼠标拖选第一个 #111 | 光标放进 #111，连按 ⌘D 四次 |
| 复制，滚到下一行粘贴 | 直接输入 #000，四处同时变 |
| 重复四遍，中间切一次窗口 | 按 Esc 退出，扫一眼确认没有多余光标 |
| 漏掉第四处，页面上有一块颜色不对 | 改错了就连按 ⌘Z 撤回重来 |

> 多光标不是更快地重复，而是把重复这个动作整个删掉。判断标准很简单：同一个改动要出现三次以上，就该换工具，而不是拼手速。

> **提示：折叠不是藏 bug 的地方**
>
> 折叠（fold）用来把已经写好、暂时不看的函数收起来，让一个屏幕装下更多结构。它不减少文件的复杂度，也不影响编译结果。真要理解一个文件，用 ⌘⇧O（Ctrl+Shift+O）打开符号列表，比一层层展开快得多。另外先格式化（⇧⌥F）再折叠，缩进才对得齐。

## 动手练一练

新建一个 .css 或 .js 文件，把下面的动作各做一遍，重点是让手指记住位置。

1. 写四行内容相同的 color 声明，用 ⌘D 一次改完
2. 用 ⌥ 点击在四行末尾各加一个光标，同时补上分号
3. 用 ⌥↑ 把最后一行一路移到最前面
4. 按 F12 跳进一个函数的定义，再用 ⌃ 减号退回来

**完成标准**：四行一次改完、整行不用选就能移动，这两件事不看笔记也能做出来。

## 小测验

<details>
<summary>展开题目与答案（3 题）</summary>

**1. 想改一个变量名，哪种做法最安全？**

- A. 用 ⌘D 逐个选中同名文字
- B. 用 F2 重命名符号
- C. 用查找替换全部替换
- D. 手动一行一行改

<details><summary>答案</summary>

**B**。F2 会按作用域改，字符串和注释里的同名文字不会被碰到；⌘D 和全部替换只认文本，改坏的地方要你自己找回来。

</details>

**2. 多光标状态下发现选多了，想只撤掉最后一个光标按什么？**

- A. Esc
- B. ⌘U（Ctrl+U）
- C. ⌘Z（Ctrl+Z）
- D. ⌘⇧L（Ctrl+Shift+L）

<details><summary>答案</summary>

**B**。⌘U 只撤掉最后加的那个光标，已经输入的内容都还在；Esc 是全部退出，⌘Z 撤回的是文本改动。

</details>

**3. F12 按下去没有任何反应，最可能的原因是什么？**

- A. 键盘按键坏了
- B. 符号没被导入当前文件，或语言服务没启动
- C. 必须先用鼠标点一下函数名
- D. 要先打开断点面板

<details><summary>答案</summary>

**B**。跳转靠语言服务解析，依赖没装、语言模式不对、tsconfig 路径写错都会让它失效；先看右下角的语言模式对不对。

</details>

</details>

# 先认识这个编辑器

> 五个区域、一个命令面板，先学会用键盘找到一切

`VS Code` · 建议 10 分钟 · 入门

## 学完这一节，你会

- 叫得出界面五个区域的名字
- 用命令面板完成一次菜单里没有的操作
- 用 ⌘P 在三秒内打开任意文件
- 在项目目录里打开集成终端并执行命令

## 打开之后，屏幕被分成五块

第一次打开 VS Code，界面看着干净，其实被切成五块。以后你所有的「找不到东西」，都能归到其中一块。

- **活动栏（Activity Bar）**：最左边一竖排图标，管资源管理器、搜索、源代码管理、运行和调试、扩展。
- **侧边栏（Side Bar）**：活动栏右边那一栏，内容随你点的图标变化。
- **编辑器区（Editor Group）**：中间写代码的地方，可以左右分栏、上下分栏。
- **面板（Panel）**：编辑器下方，装终端、问题、输出、调试控制台。
- **状态栏（Status Bar）**：最下面一行细条，显示光标行列、缩进、编码、语言模式和 Git 分支。

## 五个区域各管什么

| 区域 | 装什么 | 怎么开关 |
| --- | --- | --- |
| 活动栏 | 资源管理器、搜索、源代码管理、运行、扩展 | 命令面板里搜 Toggle Activity Bar Visibility |
| 侧边栏 | 当前入口的详细列表，比如文件树 | ⌘B（Ctrl+B） |
| 编辑器区 | 打开的文件标签页，可以拆成多栏 | 拖动标签页到边缘，或右键 Split Right |
| 面板 | 终端、问题、输出、调试控制台 | ⌘J（Ctrl+J）整体开关 |
| 状态栏 | 行列、缩进、行尾、编码、语言、分支 | 右键状态栏可以只留你关心的那几项 |

## 命令面板才是真正的入口

菜单栏里能点的，命令面板里都有；菜单栏里没有的，命令面板里更多。它做的事很简单：把编辑器全部命令按名字列出来，你只要记住名字里的几个字就能调到。

输入框最左边有一个大于号时，搜的是**命令**；把大于号删掉，同一个输入框就变成按文件名搜索。这是新手最容易卡住的地方：明明想找文件，却一直停在命令模式里，输入什么都没结果。

在快速打开（Quick Open）里还能用几个前缀：`@` 搜当前文件的符号，`:` 跳行号，`#` 搜整个工作区的符号，输入 `?` 会列出全部前缀。

## 快速打开里的四种写法

```text
app.js:42        跳到 app.js 第 42 行
@save            当前文件里找名字含 save 的符号
@:120            跳到当前文件第 120 行
#fetchUser       在整个工作区里搜这个符号
```

> 先按 ⌘P（Windows 是 Ctrl+P）打开输入框，再输入冒号或井号。输入错了按 Esc 关掉，不会改动任何文件。

## 第一次打开，按顺序做四件事

### 1. 打开文件夹，而不是打开文件

File → Open Folder 选项目根目录。VS Code 的能力几乎都以文件夹为单位：搜索范围、终端工作目录、Git 面板、插件配置。

### 2. 打开集成终端，确认它在项目里

按 ⌃ 加反引号键（Windows 是 Ctrl 加反引号）。终端里的当前目录就是刚打开的文件夹，不用再 cd 过去。

### 3. 分清两种放大

⌘ 加号放大的是整个窗口（Zoom），侧边栏和菜单一起变大；只想让代码字变大，要改设置里的 `editor.fontSize`。

### 4. 在命令面板里搜一次 Toggle

输入 Toggle 看结果有多少条。这一步是建立「每个功能都有命令名」的直觉，以后遇到找不到的开关，第一个动作就是来这里搜。

> **注意：没打开文件夹时，一半功能是哑的**
>
> 用 File → Open File 双击打开单个文件时，资源管理器会显示 `You have not yet opened a folder.`。此时搜索只在这一个文件里生效，集成终端的当前目录不是你的项目目录，源代码管理面板也看不到仓库。
>
> 这不是装坏了。回到 File → Open Folder 重新打开目录，所有面板立刻恢复。养成习惯：先开文件夹，再改代码。

> **提示：状态栏那一条细线，全是可点的**
>
> 右下角 `Spaces: 2` 点开可以改缩进宽度和是否用空格；`LF` 和 `CRLF` 是行尾序列（line ending），从 Windows 同事那里拿来的文件常带 CRLF，直接提交会让整个文件在 diff 里变成红色；`UTF-8` 是文件编码；再往左的语言模式（Plain Text、JavaScript）决定语法高亮，后缀名不常见的文件高亮不对时，点它手动指定即可。

## 在终端里打开一个项目

```bash
$ code .
```

> 在项目根目录执行，会用新窗口打开当前目录；如果已经开着同一个目录，会直接激活那个窗口。macOS 第一次用可能报 code: command not found，先在命令面板执行 Shell Command: Install code command in PATH。别在 / 或整个用户主目录下执行，那会把几十万个文件塞进搜索索引，内存和启动速度都会变差。

## 布局拖乱了怎么回来

面板标题栏可以拖到编辑器右侧，变成竖排；活动栏也能拖到右边。拖乱之后不用手动摆，命令面板里执行 `View: Reset View Locations` 一次性恢复默认布局。分栏开太多时，`View: Close All Editor Groups` 会关掉除当前之外的所有分栏，没保存的文件它会先问你。

## 动手练一练

找一个你电脑里的真实项目目录打开，下面几件事全部用键盘完成，不要点菜单栏。

1. 用 ⌘P（Ctrl+P）打开目录里任意一个文件
2. 打开集成终端，确认当前目录就是项目根目录 —— `pwd`
3. 在命令面板里执行一次 View: Toggle Panel Position
4. 点状态栏把缩进从 Spaces: 2 改成 Spaces: 4

**完成标准**：不看菜单就能打开文件、开终端、改缩进，说明五个区域你都摸到了。

## 小测验

<details>
<summary>展开题目与答案（3 题）</summary>

**1. 命令面板打开时，输入框最左边的符号代表什么？**

- A. 大于号表示当前在搜命令
- B. 大于号表示当前在搜文件
- C. 大于号表示开启了多光标
- D. 大于号没有含义，只是装饰

<details><summary>答案</summary>

**A**。带大于号时搜的是命令名；把大于号删掉，输入框就变成按文件名搜索的快速打开，两种模式共用一个入口，别混着找。

</details>

**2. 只打开了单个文件、没有打开文件夹时，哪一项会不正常？**

- A. 语法高亮
- B. 集成终端的当前目录
- C. 光标的移动
- D. 字体大小

<details><summary>答案</summary>

**B**。没有工作目录，终端会落在用户主目录下，搜索范围也只剩这一个文件，Git 面板同样看不到仓库，大部分功能都开始打折。

</details>

**3. 想让代码字号变大、侧边栏保持不变，应该怎么做？**

- A. 按 ⌘ 加号放大窗口
- B. 改设置里的 editor.fontSize
- C. 把窗口拖大一点
- D. 改设置里的 window.zoomLevel

<details><summary>答案</summary>

**B**。⌘ 加号改的是整个窗口的缩放，侧边栏和菜单会一起变大；editor.fontSize 只影响编辑器里的代码文字，两者互不干扰。

</details>

</details>
